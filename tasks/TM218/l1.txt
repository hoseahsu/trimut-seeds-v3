Numbered combat robots exchange reductions in their energy levels.

There are N combat robots, numbered 1, 2, ..., N.

Initially, the energy level of Combat robot i is A_i.

Below, a combat robot with at least 1 energy level is called active.

Until there is only one active combat robot, the following is repeated:

* A random active combat robot attacks another random active combat robot.
* As a result, the energy level of the combat robot attacked is reduced by the amount equal to the current energy level of the combat robot attacking.



Find the minimum possible final energy level of the last combat robot active.

Constraints

* All values in input are integers.
* 2 \leq N \leq 10^5
* 1 \leq A_i \leq 10^9

Input

Input is given from Standard Input in the following format:


N
A_1 A_2 ... A_N


Output

Print the minimum possible final energy level of the last combat robot active.

Examples

Input

4
2 10 8 40


Output

2


Input

4
5 13 8 1000000000


Output

1


Input

3
1000000000 1000000000 1000000000


Output

1000000000
