An organizer groups trainees from different academies into contest crews.

Marek is an organizer of a Arden ICPC regional event. There are n academies in Arden numbered from 1 to n. Marek knows all competitive trainees in the region. There are n trainees: the i-th trainee is enrolled at a academy u_i and has a technical skill s_i.

Marek has to decide on the rules now. In particular, the number of members in the crew.

Marek knows that if he chooses the size of the crew to be some integer k, each academy will send their k strongest (with the highest technical skill s) trainees in the first crew, the next k strongest trainees in the second crew and so on. If there are fewer than k trainees left, then the crew can't be formed. Note that there might be academies that send zero crews.

The strength of the region is the total skill of the members of all present crews. If there are no crews present, then the strength is 0.

Help Marek to find the strength of the region for each choice of k from 1 to n.

Input

The first line contains a single integer t (1 ≤ t ≤ 1000) — the number of testcases.

The first line of each testcase contains a single integer n (1 ≤ n ≤ 2 ⋅ 10^5) — the number of academies and the number of trainees.

The second line of each testcase contains n integers u_1, u_2, ..., u_n (1 ≤ u_i ≤ n) — the academy the i-th trainee is enrolled at.

The third line of each testcase contains n integers s_1, s_2, ..., s_n (1 ≤ s_i ≤ 10^9) — the technical skill of the i-th trainee.

The sum of n over all testcases doesn't exceed 2 ⋅ 10^5.

Output

For each testcase print n integers: the strength of the region — the total skill of the members of the present crews — for each choice of crew size k.
