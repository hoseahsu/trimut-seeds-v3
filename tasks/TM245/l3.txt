# accumulate

## Problem Statement


You are given an array $a$ with infinite length. Initially, all elements are $0$. Process the following $Q$ queries in order.

- `0 $k$ $v$`: $a[k] \gets a[k]+v$
- `1 $k$`: Print $a[k]$

## Constraints

- $1 \leq Q \leq 1000000$
- $0 \leq k, v \leq 1000000000000000000$

## Input

```
$Q$
$\textrm{Query}_0$
$\textrm{Query}_1$
:
$\textrm{Query}_{Q - 1}$
```


## Sample Input 1

```
8
0 1 2
1 1
1 2
0 2 3
1 1
1 2
0 2 1
1 2
```

## Sample Output 1

```
2
0
2
3
4
```
