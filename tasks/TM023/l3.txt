There exists an island called Arpa’s land, some beautiful girls live there, as ugly ones do.

Mehrdad wants to become minister of Arpa’s land. Arpa has prepared an exam. Exam has only one question, given n, print the last two digits of 1378^n (as an integer in [0,99], without mandatory leading zero padding). 

![Original illustration 1](https://espresso.codeforces.com/ac805c7c78540a009fed5a8407fb3448d2a085a6.png)

Mehrdad has become quite confused and wants you to help him. Please help, although it's a naive cheat.

Input

The single line of input contains one integer n (0 ≤ n ≤ 10^9).

Output

Print single integer — the last two digits of 1378^n (as an integer in [0,99], without mandatory leading zero padding).

Sample Input 1

```text
2
```

Sample Output 1

```text
84
```

Sample Input 2

```text
1
```

Sample Output 2

```text
78
```
