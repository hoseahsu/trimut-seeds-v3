An apprentice takes a certification examination at a research academy.

There exists an academy called Arden Academy, some celebrated researchers live there, as unassuming ones do.

Dorian wants to become director of Arden Academy. Arden has prepared an exam. Exam has only one question, given n, print the last digit of 1378^n. 

![Original illustration 1](https://espresso.codeforces.com/ac805c7c78540a009fed5a8407fb3448d2a085a6.png)

Dorian has become quite confused and wants you to help him. Please help, although it's a naive cheat.

Input

The single line of input contains one integer n (0 ≤ n ≤ 10^9).

Output

Print single integer — the last digit of 1378^n.

Examples

Input

1


Output

8

Input

2


Output

4

Note

In the first example, last digit of 1378^1 = 1378 is 8.

In the second example, last digit of 1378^2 = 1378·1378 = 1898884 is 4.
