A visitor exchanges chosen codes for collectible tokens.

Marek loves tokens! He visits the Binary Exchange to buy some of his favorite collectible tokens.  
The owner of the exchange, Nolan, is a clever man. He does not want Marek to finish all his collectible tokens. Hence, he plays a game.
The Marek is given N numbers and has to select K of these numbers. For each number that Marek chooses, he will get as many collectible tokens as the number of 1's in the Binary representation of the number i.e. the number of bits that are set.
Help Marek find the maximum number of tokens that he can have.  

Input:
The first line of input contains T. T test cases follow.
First line of each test cases contains 2 space-separated integers N and K.
The next line contains N space-separated integers.  

Output:
For each test cases, print the answer in a new line.  

Constraints:
1 ≤ T ≤ 10
1 ≤ N ≤ 10^3
0 ≤ K ≤ N
0 ≤ Numbers ≤ 10^5

SAMPLE INPUT
1
4 2
6 1 2 0

SAMPLE OUTPUT
3

Explanation

He chooses numbers 6 (110)  and 1 (001) with 2 and 1 set bits respectively.
