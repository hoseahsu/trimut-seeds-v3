A dispatch office balances jobs among workstations.

In the dispatch office there are n workstations which are responsible for processing several scheduled jobs. You know the number of scheduled jobs for each workstation: there are mi jobs assigned to the i-th workstation.

In order to balance the load for each workstation, you want to reassign some jobs to make the difference between the most loaded workstation and the least loaded workstation as small as possible. In other words you want to minimize expression ma - mb, where a is the most loaded workstation and b is the least loaded one.

In one second you can reassign a single job. Thus in one second you can choose any pair of workstations and move a single job from one workstation to another.

Write a program to find the minimum number of seconds needed to balance the load of workstations.

Input

The first line contains positive number n (1 ≤ n ≤ 10^5) — the number of the workstations. 

The second line contains the sequence of non-negative integers m1, m2, ..., mn (0 ≤ mi ≤ 2·10^4), where mi is the number of jobs assigned to the i-th workstation.

Output

Print the minimum number of seconds required to balance the load.

Examples

Input

2
1 6


Output

2


Input

7
10 11 10 11 10 11 11


Output

0


Input

5
1 2 3 4 5


Output

3

Note

In the first example two seconds are needed. In each second, a single job from workstation #2 should be moved to workstation #1. After two seconds there should be 3 jobs on workstation #1 and 4 jobs on workstation #2.

In the second example the load is already balanced.

A possible sequence of job movements for the third example is:

  1. move a job from workstation #4 to workstation #1 (the sequence m becomes: 2 2 3 3 5); 
  2. then move job from workstation #5 to workstation #1 (the sequence m becomes: 3 2 3 3 4); 
  3. then move job from workstation #5 to workstation #2 (the sequence m becomes: 3 3 3 3 3). 



The above sequence is one of several possible ways to balance the load of workstations in three seconds.
