A builder assembles an ordered chain of coded flight modules.

Mira is going to fly to Arden Station. She needs to build a flight chain, which consists of several modules in some order. Each of the modules is defined by a lowercase Latin letter. This way, the flight chain can be described by the string — concatenation of letters, which correspond to the modules.

There are n modules available. The flight chain must contain exactly k of them. Modules in the flight chain should be ordered by their weight. So, after the module with some letter can go only module with a letter, which is at least two positions after in the alphabet (skipping one letter in between, or even more). For example, after letter 'c' can't go letters 'a', 'b', 'c' and 'd', but can go letters 'e', 'f', ..., 'z'.

For the flight chain to fly as far as possible, its weight should be minimal. The weight of the flight chain is equal to the sum of the weights of its modules. The weight of the module is the number of its letter in the alphabet. For example, the module 'a 'weighs one ton,' b 'weighs two tons, and' z' — 26 tons.

Build the flight chain with the minimal weight or determine, that it is impossible to build a flight chain at all. Each module can be used at most once.

Input

The first line of input contains two integers — n and k (1 ≤ k ≤ n ≤ 50) – the number of available modules and the number of modules to use in the flight chain.

The second line contains string s, which consists of exactly n lowercase Latin letters. Each letter defines a new module, which can be used to build the flight chain. Each module can be used at most once.

Output

Print a single integer — the minimal total weight of the flight chain or -1, if it is impossible to build the flight chain at all.

Examples

Input

5 3
xyabd


Output

29

Input

7 4
problem


Output

34

Input

2 2
ab


Output

-1

Input

12 1
abaabbaaabbb


Output

1

Note

In the first example, the following rockets satisfy the condition:

  * "adx" (weight is 1+4+24=29);
  * "ady" (weight is 1+4+25=30);
  * "bdx" (weight is 2+4+24=30);
  * "bdy" (weight is 2+4+25=31).



Flight chain "adx" has the minimal weight, so the answer is 29.

In the second example, target flight chain is "belo". Its weight is 2+5+12+15=34.

In the third example, n=k=2, so the flight chain must have both modules: 'a' and 'b'. This flight chain doesn't satisfy the condition, because these letters are adjacent in the alphabet. Answer is -1.
