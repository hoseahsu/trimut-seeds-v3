# Junctions

A changing tree connects junctions with recorded quantities.


## Problem Statement


Given tree of $N$ junctions. Connections are $(u_i, v_i)$. Value $a_i$ is written on junction $i$.

Process the following $Q$ queries in order. You can assume that the graph is always the tree while processing the queries.

- `0 $u$ $v$ $w$ $x$`: Delete a connection $(u, v)$, and add $(w, x)$.
- `1 $p$ $x$`: $a_p \gets a_p + x$
- `2 $u$ $v$`: Print the sum of values of junctions of the path between $u$ and $v$ (inclusive).


## Constraints



- $1 \leq N, Q \leq 200,000$
- $0 \leq a_i, x \leq 10^9$
- $0 \leq p, u_i, v_i < N$
- $(u_i, v_i)$ is tree.
- for type 0 queries, there is a connection $(u, v)$.
- The graph is always tree.



## Input

~~~
$N$ $Q$
$a_0$ $a_1$ ... $a_{N - 1}$
$u_0$ $v_0$
$u_1$ $v_1$
:
$u_{N - 2}$ $v_{N - 2}$
$\textrm{Query}_0$
$\textrm{Query}_1$
:
$\textrm{Query}_{Q - 1}$
~~~

## Sample Input 1

```
5 7
1 10 100 1000 10000
0 1
1 2
2 3
1 4
2 0 3
1 1 100000
2 3 4
0 1 2 2 0
2 3 4
0 2 3 3 1
2 2 3
```

## Sample Output 1

```
1111
111110
111111
101111
```
