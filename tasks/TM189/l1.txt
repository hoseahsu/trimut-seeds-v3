Control toggles determine the states of indicator beacons.

We have N control toggles with "on" and "off" state, and M indicator beacons. The control toggles are numbered 1 to N, and the indicator beacons are numbered 1 to M.

Indicator beacon i is connected to k_i control toggles: Control toggle s_{i1}, s_{i2}, ..., and s_{ik_i}. It is lighted when the number of control toggles that are "on" among these control toggles is congruent to p_i modulo 2.

How many combinations of "on" and "off" states of the control toggles light all the indicator beacons?

Constraints

* 1 \leq N, M \leq 10
* 1 \leq k_i \leq N
* 1 \leq s_{ij} \leq N
* s_{ia} \neq s_{ib} (a \neq b)
* p_i is 0 or 1.
* All values in input are integers.

Input

Input is given from Standard Input in the following format:


N M
k_1 s_{11} s_{12} ... s_{1k_1}
:
k_M s_{M1} s_{M2} ... s_{Mk_M}
p_1 p_2 ... p_M


Output

Print the number of combinations of "on" and "off" states of the control toggles that light all the indicator beacons.

Examples

Input

2 2
2 1 2
1 2
0 1


Output

1


Input

2 3
2 1 2
1 1
1 2
0 0 1


Output

0


Input

5 2
3 1 2 5
2 2 3
1 0


Output

8
