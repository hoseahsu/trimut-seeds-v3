A display crew raises figures using support blocks.

N figures are standing in a row. The height of the i-th figure from the front is A_i.

We want to have each figure stand on a support block of some heights - at least zero - so that the following condition is satisfied for every figure:

Condition: Nobody in front of the figure is taller than the figure. Here, the height of a figure includes the support block.

Find the minimum total height of the support blocks needed to meet this goal.

Constraints

* 1 \leq N \leq 2\times 10^5
* 1 \leq A_i \leq 10^9
* All values in input are integers.

Input

Input is given from Standard Input in the following format:


N
A_1 \ldots A_N


Output

Print the minimum total height of the support blocks needed to meet the goal.

Examples

Input

5
2 1 5 4 3


Output

4


Input

5
3 3 3 3 3


Output

0
