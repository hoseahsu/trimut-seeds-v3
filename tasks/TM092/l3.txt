Given is a positive integer N. How many tuples (A,B,C) with positive integers A and B and a nonnegative integer C satisfy A \times B + C = N?

Constraints

* 2 \leq N \leq 10^6
* All values in input are integers.

Input

Input is given from Standard Input in the following format:


N


Output

Print the answer.

Sample Input 1

```text
3
```

Sample Output 1

```text
5
```

Sample Input 2

```text
100
```

Sample Output 2

```text
482
```

Sample Input 3

```text
1000000
```

Sample Output 3

```text
13970034
```
