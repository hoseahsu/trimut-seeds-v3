A distributor splits indivisible parcels between two recipients.

Marek has bought n parcels for Mira and Nolan. Now he wants to divide all the parcels between the friends.

Each parcel weights 100 grams or 200 grams. Of course Marek doesn't want to offend any of his friend. Therefore the total weight of the parcels given to Mira must be equal to the total weight of the parcels given to Nolan.

But unfortunately Marek doesn't have a cutting tool right now, so he cannot split any parcel into some parts. Please, tell him: is it possible to divide all the parcels in a fair way between his friends?

Input

The first line contains an integer n (1 ≤ n ≤ 100) — the number of parcels. The second line contains n integers w1, w2, ..., wn (wi = 100 or wi = 200), where wi is the weight of the i-th parcel.

Output

In a single line print "YES" (without the quotes) if it is possible to divide all the parcels between his friends. Otherwise print "NO" (without the quotes).

Examples

Input

3
100 200 100


Output

YES


Input

4
100 100 100 200


Output

NO

Note

In the first test sample Marek can give the first and the last parcel to Nolan and the middle parcel to Mira.
