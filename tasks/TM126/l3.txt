Some days ago, I learned the concept of LCM (least common multiple). I've played with it for several times and I want to make a big number with it.

But I also don't want to use many numbers, so I'll choose two positive integers (they don't have to be distinct) which are not greater than n. Can you help me to find the maximum possible least common multiple of these two integers?

Input

The first line contains an integer n (1 ≤ n ≤ 10^6) — the n mentioned in the statement.

Output

Print a single integer — the maximum possible LCM of two not necessarily distinct positive integers that are not greater than n.

Sample Input 1

```text
9
```

Sample Output 1

```text
72
```

Sample Input 2

```text
7
```

Sample Output 2

```text
42
```
