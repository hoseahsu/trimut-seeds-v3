An operator removes stored modules from a terminal.

Marek often uses his terminal. He has already installed n stored modules on it. Stored module with number i takes up a_i units of memory.

Marek wants to free at least m units of memory (by removing some stored modules).

Of course, some stored modules are more important to Marek than others. He came up with the following scoring system — he assigned an integer b_i to each stored module: 

  * b_i = 1 — regular stored module; 
  * b_i = 2 — important stored module. 



According to this rating system, his terminal has b_1 + b_2 + … + b_n utility points.

Marek believes that if he removes stored modules with numbers i_1, i_2, …, i_k, then he will free a_{i_1} + a_{i_2} + … + a_{i_k} units of memory and lose b_{i_1} + b_{i_2} + … + b_{i_k} utility points.

For example, if n=5, m=7, a=[5, 3, 2, 1, 4], b=[2, 1, 1, 2, 1], then Marek can uninstall the following stored module sets (not all options are listed below): 

  * stored modules with numbers 1, 4 and 5. In this case, it will free a_1+a_4+a_5=10 units of memory and lose b_1+b_4+b_5=5 utility points; 
  * stored modules with numbers 1 and 3. In this case, it will free a_1+a_3=7 units of memory and lose b_1+b_3=3 utility points. 
  * stored modules with numbers 2 and 5. In this case, it will free a_2+a_5=7 memory units and lose b_2+b_5=2 utility points. 



Help Marek, choose a set of stored modules, such that if removing them will free at least m units of memory and lose the minimum number of utility points, or indicate that such a set does not exist.

Input

The first line contains one integer t (1 ≤ t ≤ 10^4) — the number of test cases. Then t test cases follow.

The first line of each test case contains two integers n and m (1 ≤ n ≤ 2 ⋅ 10^5, 1 ≤ m ≤ 10^9) — the number of stored modules on Marek's terminal and the number of memory units to be freed.

The second line of each test case contains n integers a_1, a_2, …, a_n (1 ≤ a_i ≤ 10^9) — the number of memory units used by stored modules.

The third line of each test case contains n integers b_1, b_2, …, b_n (1 ≤ b_i ≤ 2) — the utility points of each stored module.

It is guaranteed that the sum of n over all test cases does not exceed 2 ⋅ 10^5.

Output

For each test case, output on a separate line: 

  * -1, if there is no set of stored modules, removing which will free at least m units of memory; 
  * the minimum number of utility points that Marek will lose if such a set exists. 

Example

Input


5
5 7
5 3 2 1 4
2 1 1 2 1
1 3
2
1
5 10
2 3 2 3 2
1 2 1 2 1
4 10
5 1 3 4
1 2 1 2
4 5
3 2 1 2
2 1 2 1


Output


2
-1
6
4
3

Note

In the first test case, it is optimal to remove stored modules with numbers 2 and 5, freeing 7 units of memory. b_2+b_5=2.

In the second test case, by removing the only stored module, Marek will be able to clear only 2 of memory units out of the 3 needed.

In the third test case, it is optimal to remove stored modules with numbers 1, 2, 3 and 4, freeing 10 units of memory. b_1+b_2+b_3+b_4=6.

In the fourth test case, it is optimal to remove stored modules with numbers 1, 3 and 4, freeing 12 units of memory. b_1+b_3+b_4=4.

In the fifth test case, it is optimal to remove stored modules with numbers 1 and 2, freeing 5 units of memory. b_1+b_2=3.
