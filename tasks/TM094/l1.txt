A measurement register supplies a subset of recorded values.

you are given an measurement register of size N. You need to select K readings from the measurement register such that the difference between the max number among selected and the min number among selected measurement register readings should be minimum. Print the minimum difference.

INPUT:
First line N number i.e., length of measurement register
Second line K number 
Next N lines contains a number for each line

OUTPUT:
Print the minimum possible difference

0<N<10^5
0<K<N
0<number<10^9

SAMPLE INPUT
5
3
1
2
3
4
5

SAMPLE OUTPUT
2
