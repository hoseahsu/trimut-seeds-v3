# nondecreasing

## Problem Statement


You are given an integer sequence $A$ with the length $N$. Find a longest nondecreasing subsequence of $A$.


A nondecreasing subsequence uses strictly increasing indices and allows equal consecutive values.

## Constraints

- $1 \leq N \leq 500000$
- $0 \leq A_i \leq 1000000000$

## Input

~~~
$N$
$A_0$ $A_1$ $\dots$ $A_{N - 1}$
~~~

## Output


On line $1$, output the maximum length $K$ of an nondecreasing subsequence of $A$.
On line $2$, Print an nondecreasing subsequence of length $K$. 
$i_k$ is the index of the kth element of the subsequence.

```
$K$
$i_0$ $i_1$ $\dots$ $i_{K - 1}$
```



## Sample Input 1

```
5
3 1 4 1 5
```

## Sample Output 1

```
3
1 3 4
```

## Sample Input 2

```
5
3 3 2 3 1
```

## Sample Output 2

```
3
0 1 3
```
