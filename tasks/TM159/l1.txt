An operator uses two pulse emitters to meet an exact target level.

Marek is engaged in a fight with "The Savior". Before he can fight it with his sword, he needs to break its shields. He has two pulse emitters, Slate and Pearl, each of them is able to perform any non-negative number of pulses.

For every pulse that hits the shield, Slate deals a units of impact while Pearl deals b units of impact. In order to break the shield Marek has to deal exactly c units of impact. Find out if this is possible.

Input

The first line of the input contains three integers a, b, c (1 ≤ a, b ≤ 100, 1 ≤ c ≤ 10 000) — the number of units of impact dealt by Slate pulse emitter and Pearl pulse emitter, and the total number of impact required to break the shield, respectively.

Output

Print "Yes" (without quotes) if Marek can deal exactly c impact to the shield and "No" (without quotes) otherwise.

Examples

Input

4 6 15


Output

No


Input

3 2 7


Output

Yes


Input

6 11 6


Output

Yes

Note

In the second sample, Marek can fire 1 pulse from Slate and 2 from Pearl to deal exactly 1·3 + 2·2 = 7 impact. In the third sample, Marek can fire 1 pulse from Slate and no bullets from Pearl to do 1·6 + 0·11 = 6 impact.
