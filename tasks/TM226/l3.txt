# maximum Cartesian tree

## Problem Statement



You are given a sequence $A = (a_0, a_1, \dots, a _ {N-1})$ of distinct integers.
Construct the Cartesian tree derived from this sequence $A$.
The largest element becomes the root.



## Constraints

- $1 \leq N \leq 1000000$
- $0 \leq a_i \leq 1000000000$
- $i \ne j$ implies $a_i \ne a_j$
- all values are integers

## Input

~~~
$N$
$a_0$ $a_1$ ... $a _ {N - 1}$
~~~

## Output

~~~
$p_0$ $p_1$ $p_2$ ... $p_{N - 1}$
~~~


$p_i$ is the parent of vertex $i$. $p_r = r$ for the root node $r$ of the tree.




## Sample Input 1

```
3
1 0 2
```

## Sample Output 1

```
2 0 2
```

## Sample Input 2

```
11
9 3 7 1 8 12 10 20 15 18 5
```

## Sample Output 2

```
5 2 4 2 0 7 5 7 9 7 9
```
