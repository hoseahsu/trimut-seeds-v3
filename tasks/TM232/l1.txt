# Integer identifier set

The set stores active integer identifiers.


## Problem Statement


Let $S$ be an empty integer identifier set.
Process the following $Q$ registry requests :

 - `0 x` : insert $x$ into $S$ if it is not in $S$
 - `1 x` : remove $x$ from $S$ if it is in $S$
 - `2 x` : find $\min_{i \in S}(i \oplus x)$ where $\oplus$ denotes bitwise-xor.



## Constraints


 - $1 \leq Q \leq 500000$
 - $0 \le x \lt 2^{30}$
 - $S$ is not empty when processing registry requests of type `2 x`.



## Input

```
$Q$
$\mathrm{Query}_0$
$\mathrm{Query}_1$
$\mathrm{Query}_2$
$\hspace{15pt} \vdots$
$\mathrm{Query}_{Q - 1}$
```

## Sample

## Sample Input 1

```
6
0 6
0 7
2 5
1 7
1 10
2 7
```

## Sample Output 1

```
2
1
```
