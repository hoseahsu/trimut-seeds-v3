# Number of Substrings

## Problem Statement



Given a length $N$ string $S$. Count the number of __distinct__ substrings of $S$.



## Constraints



- $1 \leq N \leq 500,000$
- Each character of $S$ is lowercase English letters.



## Input

~~~
$S$
~~~

## Output

~~~
$ans$
~~~

## Sample

## Sample Input 1

```
abcbcba
```

## Sample Output 1

```
21
```

## Sample Input 2

```
mississippi
```

## Sample Output 2

```
53
```

## Sample Input 3

```
ababacaca
```

## Sample Output 3

```
33
```

## Sample Input 4

```
aaaaa
```

## Sample Output 4

```
5
```
