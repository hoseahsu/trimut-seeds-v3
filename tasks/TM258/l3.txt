# even-length distinct

## Problem Statement



Given a length $N$ string $S$. Count the number of __distinct__ nonempty substrings of even length of $S$.



## Constraints



- $1 \leq N \leq 500,000$
- Each character of $S$ is lowercase English letters.



## Input

~~~
$S$
~~~

## Output

~~~
$ans$
~~~


## Sample Input 1

```
abcbcba
```

## Sample Output 1

```
10
```

## Sample Input 2

```
mississippi
```

## Sample Output 2

```
26
```

## Sample Input 3

```
ababacaca
```

## Sample Output 3

```
16
```

## Sample Input 4

```
aaaaa
```

## Sample Output 4

```
2
```
