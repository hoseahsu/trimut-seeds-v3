A designer converts a permutation into a branching hierarchy.

A permutation — is a sequence of length n integers from 1 to n, in which all the numbers occur exactly once. For example, [1], [3, 5, 2, 1, 4], [1, 3, 2] — permutations, and [2, 3, 2], [4, 3, 1], [0] — no.

Marek was recently gifted a permutation a[1 ... n] of length n. Marek likes branching hierarchies more than permutations, so he wants to transform permutation a into a rooted binary branching hierarchy. He transforms an array of different integers into a branching hierarchy as follows: 

  * the maximum element of the array becomes the root of the branching hierarchy; 
  * all elements to the left of the maximum — form a left subtree (which is built according to the same rules but applied to the left part of the array), but if there are no elements to the left of the maximum, then the root has no left child; 
  * all elements to the right of the maximum — form a right subtree (which is built according to the same rules but applied to the right side of the array), but if there are no elements to the right of the maximum, then the root has no right child. 



For example, if he builds a branching hierarchy by permutation a=[3, 5, 2, 1, 4], then the root will be the element a_2=5, and the left subtree will be the branching hierarchy that will be built for the subarray a[1 ... 1] = [3], and the right one — for the subarray a[3 ... 5] = [2, 1, 4]. ![Original illustration 2](https://espresso.codeforces.com/181e3c437e662626ca7fa36945cc6965098a8558.png) The branching hierarchy corresponding to the permutation a=[1, 3, 2, 7, 5, 6, 4].

Let us denote by d_v the depth of the hierarchy node a_v, that is, the number of edges on the path from the root to the hierarchy node numbered a_v. Note that the root depth is zero. Given the permutation a, for each hierarchy node, find the value of d_v.

Input

The first line contains one integer t (1 ≤ t ≤ 100) — the number of test cases. Then t test cases follow.

The first line of each test case contains an integer n (1 ≤ n ≤ 100) — the length of the permutation.

This is followed by n numbers a_1, a_2, …, a_n — permutation a.

Output

For each test case, output n values — d_1, d_2, …, d_n.

Example

Input


3
5
3 5 2 1 4
1
1
4
4 3 1 2


Output


1 0 2 3 1 
0 
0 1 3 2
