# Boundary stations

The polygon vertices are boundary stations on a convex perimeter.


## Problem Statement


This problem has $T$ cases.

You are given the boundary stations $p_i(x_i, y_i)$ ($0 \leq i < N$) of a strictly convex polygon in counterclockwise order.

For every $i$, find an index $f_i$ ($0 \leq f_i < N$) such that

$$
\operatorname{dist}(p_i, p_{f_i}) = \max_{0 \leq j < N}\operatorname{dist}(p_i, p_j).
$$

Here, $\operatorname{dist}$ denotes the Euclidean distance. If there are multiple possible $f_i$, you may output any of them.



## Constraints



- $1 \leq T \leq 100000$
- $3 \leq N \leq 500000$
- $|x_i|, |y_i| \leq 1000000000$
- All input values are integers.
- $p_0, p_1, \dots, p_{N-1}$ are the distinct boundary stations of a strictly convex polygon in counterclockwise order.
- The sum of $N$ over all test cases does not exceed $500000$.



## Input

```
$T$
$N$
$x_0$ $y_0$
$x_1$ $y_1$
$\vdots$
$x_{N-1}$ $y_{N-1}$
$\vdots$
```

## Output


For each test case, output the answer in the following format.


```
$f_0$ $f_1$ $\ldots$ $f_{N-1}$
```
