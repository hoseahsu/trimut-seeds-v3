# alphabet order reversal

## Problem Statement



For a string $X = X _ 0 X _ 1 X _ 2 \cdots $ , we denote its substring $X _ a X _ {a+1} \cdots X _ {b-1}$ as $X[a,b)$ .

Given a string $S = S _ 0 S _ 1 S _ 2 \cdots S _ {N-1}$ of length $N$ . Find an array of integers $0 = a _ 0 \lt a _ 1 \lt a _ 2 \lt \ldots \lt a _ k = N$ so that $S[a _ 0 , a _ 1) , S[a _ 1 , a _ 2) , \ldots , S[a _ {k-1} , a _ k)$ is the Lyndon Factorization of $S$ under the alphabet order $z<y<\cdots<a$. In this order a proper prefix is still smaller than the longer string. A nonempty string is Lyndon if it is strictly smaller than each of its nonempty proper suffixes; its Lyndon factorization is the unique decomposition into a lexicographically nonincreasing sequence of Lyndon strings .



## Constraints



- $1 \leq N \leq 500000$
- Each character of $S$ is a lowercase English letter.



## Input

~~~
$S$
~~~

## Output

~~~
$a _ 0$ $a _ 1$ $a _ 2$ $\cdots$ $a _ k$
~~~


## Sample Input 1

```
babaabaab
```

## Sample Output 1

```
0 8 9
```

## Sample Input 2

```
ababacaca
```

## Sample Output 2

```
0 1 3 5 7 9
```
