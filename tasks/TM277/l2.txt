# Chromatic Number

## Problem Statement


Given a simple undirected graph with $N$ vertices and $M$ edges. $i$-th edge is $\lbrace u_i, v_i\rbrace$。

Calculate the chromatic number $C$.



## Constraints

- $1 \leq N \leq 21$
- $0 \leq M \leq \frac{N(N-1)}{2}$
- $0 \leq u_i, v_i < N$
- $u_i \neq v_i$
- $\lbrace u_i, v_i\rbrace \neq \lbrace u_j, v_j\rbrace$

## Input

~~~
$N$ $M$
$u_0$ $v_0$
$u_1$ $v_1$
:
$u_{M - 1}$ $v_{M - 1}$
~~~

## Output

~~~
$C$
~~~

## Sample

## Sample Input 1

```
5 7
0 1
0 2
0 4
1 3
2 3
2 4
3 4
```

## Sample Output 1

```
3
```

## Sample Input 2

```
20 0
```

## Sample Output 2

```
1
```
