The given integers specify a numeric interval and a target identifier.

How Many Divisors?

Write a program which reads three integer parameters a, b and c, and prints the number of divisors of target c between a and b.

Constraints

* 1 ≤ a, b, c ≤ 10000
* a ≤ b

Input

Three integer parameters a, b and c are given in a line separated by a single space.

Output

Print the number of divisors in a line.

Example

Input

5 14 80


Output

3
