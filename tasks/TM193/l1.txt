A designer selects projects to mention in a work portfolio.

Marek Nolan has just quit his job at Arden Studio. Now he is going to find a new place to work. Despite being such a well-known person, he still needs a Portfolio to apply for a job.

During all his career Marek has produced n projects. Some of them were successful, some were not. Marek wants to remove several of them (possibly zero) from his Portfolio to make a better impression on employers. As a result there should be no unsuccessful project which comes right after successful one in his Portfolio.

More formally, you are given an array s1, s2, ..., sn of zeros and ones. Zero corresponds to an unsuccessful project, one — to a successful one. Projects are given in order they were produced, and Marek can't swap these values. He should remove some elements from this array in such a way that no zero comes right after one.

Besides that, Marek still wants to mention as much projects in his Portfolio as possible. Help this genius of a man determine the maximum number of projects he can leave in his Portfolio.

Input

The first line contains one integer number n (1 ≤ n ≤ 100).

The second line contains n space-separated integer numbers s1, s2, ..., sn (0 ≤ si ≤ 1). 0 corresponds to an unsuccessful project, 1 — to a successful one.

Output

Print one integer — the maximum number of projects Marek can leave in his Portfolio so that no unsuccessful project comes after a successful one.

Examples

Input

4
1 1 0 1


Output

3


Input

6
0 1 0 0 1 0


Output

4


Input

1
0


Output

1
