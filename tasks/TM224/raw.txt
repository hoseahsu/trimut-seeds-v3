# Line Add Get Min

## Problem Statement


There are $N$ straight lines $y = a_i x + b_i$. Process $Q$ queries.

- `0 $a$ $b$`: Add a straight line $y = ax + b$.
- `1 $p$`: Find the minimal $y$ at $x = p$.


## Constraints

- $1 \leq N, Q \leq 200000$
- $|a_i|, |p| \leq 1000000000$
- $|b_i| \leq 1000000000000000000$

## Input

~~~
$N$ $Q$
$a_0$ $b_0$
$a_1$ $b_1$
:
$a_{N-1}$ $b_{N-1}$
$\textrm{Query}_0$
$\textrm{Query}_1$
:
$\textrm{Query}_{Q - 1}$
~~~

## Sample Input 1

```
2 8
-1 -1
0 1
1 -1
1 -2
1 0
1 2
0 0 -10
1 -2
1 0
1 2
```

## Sample Output 1

```
0
1
-1
-3
-10
-10
-10
```
