An arranger revises a coded chime sequence.

Marek has just finished creating his latest chime arrangement and will present it tomorrow to the people of Arden. Unfortunately, the melody is rather dull and highly likely won't be met with a warm reception. 

His chime sequence consists of n tone codes, which we will treat as positive integers. The diversity of a chime sequence is the number of different tone codes it contains. As a patron of music, Mira watches over composers and guides them throughout the process of creating new arrangements. She decided to help Marek by changing his chime sequence to make it more diverse.

Being a minor goddess, she cannot arbitrarily change the chime sequence. Instead, for each of the n tone codes in the chime sequence, she can either leave it as it is or increase it by 1.

Given the chime sequence as a sequence of integers describing the tone codes, find out the maximal, achievable diversity.

Input

The input consists of multiple test cases. The first line contains an integer t (1 ≤ t ≤ 10 000) — the number of test cases. Then t test cases follow, each one is described in two lines.

In the first line of each test case there is a single integer n (1 ≤ n ≤ 10^5) denoting the length of the chime sequence. The next line contains a sequence of n integers x_1, x_2, …, x_n (1 ≤ x_1 ≤ x_2 ≤ … ≤ x_n ≤ 2 ⋅ n), describing the chime sequence.

The sum of n over all test cases does not exceed 10^5.

Output

For each test case, you should output a single line containing precisely one integer, the maximal diversity of the chime sequence, i.e. the maximal possible number of different elements in the final sequence.

Example

Input


5
6
1 2 2 2 5 6
2
4 4
6
1 1 3 4 4 5
1
1
6
1 1 1 2 2 2


Output


5
2
6
1
3

Tone code

In the first test case, Mira can increase the second, fifth and sixth element to obtain the sequence 1, \underline{3}, 2, 2, \underline{6}, \underline{7}, which has 5 different elements (increased elements are underlined).

In the second test case, Mira can increase the first element to obtain the sequence \underline{5}, 4, which has 2 different elements.

In the third test case, Mira can increase the second, fifth and sixth element to obtain the sequence 1, \underline{2}, 3, 4, \underline{5}, \underline{6}, which has 6 different elements.
