# maximum spanning tree

## Problem Statement



Given a weighted undirected graph with $N$ vertices and $M$ edges. The $i$-th edge is $(a_i, b_i)$ and has a weight of $c_i$. This graph may not be simple.
Find the maximum spanning tree.



## Constraints

 

- $1 \leq N \leq 500000$
- $N - 1 \leq M \leq 500000$
- $0 \leq a_i, b_i < N$
- $0 \leq c_i \leq 1000000000$
- The given graph is connected. 



## Input

~~~
$N$ $M$
$a_0$ $b_0$ $c_0$
$a_1$ $b_1$ $c_1$
:
$a_{M - 1}$ $b_{M - 1}$ $c_{M - 1}$
~~~

## Output

~~~
$X$
$e_0$ $e_1$ $e_2$ ... $e_{N - 2}$
~~~


$X$ is the sum of the weights of the edges in the maximum spanning tree. $e_i$ is the index of the edge in the maximum spanning tree.
If there are multiple correct output, print any of them.




## Sample Input 1

```
4 7
0 1 4
0 2 2
0 3 3
1 2 6
1 3 8
2 3 1
1 1 0
```

## Sample Output 1

```
18
4 3 0
```

## Sample Input 2

```
4 3
0 1 1
1 2 2
3 1 3
```

## Sample Output 2

```
6
2 1 0
```

## Sample Input 3

```
6 5
0 1 1000000000
1 2 1000000000
2 3 1000000000
3 4 1000000000
4 5 1000000000
```

## Sample Output 3

```
5000000000
0 1 2 3 4
```
