A trainee practices by selecting exercise collections.

Marek wants to train before another skills competition. During the first day of his training he should solve exactly 1 exercise, during the second day — exactly 2 exercises, during the third day — exactly 3 exercises, and so on. During the k-th day he should solve k exercises.

Marek has a list of n exercise collections, the i-th exercise collection consists of a_i exercises. During each day Marek has to choose exactly one of the exercise collections he didn't solve yet and solve it. He solves exactly k exercises from this exercise collection. Other exercises are discarded from it. If there are no exercise collections consisting of at least k exercises that Marek didn't solve yet during the k-th day, then Marek stops his training.

How many days Marek can train if he chooses the exercise collections optimally?

Input

The first line of the input contains one integer n (1 ≤ n ≤ 2 ⋅ 10^5) — the number of exercise collections.

The second line of the input contains n integers a_1, a_2, ..., a_n (1 ≤ a_i ≤ 2 ⋅ 10^5) — the number of exercises in the i-th exercise collection.

Output

Print one integer — the maximum number of days Marek can train if he chooses the exercise collections optimally.

Examples

Input


4
3 1 4 1


Output


3


Input


3
1 1 1


Output


1


Input


5
1 1 1 2 2


Output


2
