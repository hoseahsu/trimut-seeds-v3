An infinite indexed storage facility redistributes its resident records.

Arden's Archive is a very unusual archive since the number of storage slots is infinite! In fact, there is exactly one storage slot for every integer, including zero and negative integers. Even stranger, the archive is currently at full capacity, meaning there is exactly one record in every storage slot. The archive's manager, Nolan Arden himself, decides he wants to shuffle the records around because he thinks this will create a empty slot (a storage slot without a record).

For any integer k and positive integer n, let kmod n denote the remainder when k is divided by n. More formally, r=kmod n is the smallest non-negative integer such that k-r is divisible by n. It always holds that 0≤ kmod n≤ n-1. For example, 100mod 12=4 and (-1337)mod 3=1.

Then the shuffling works as follows. There is an array of n integers a_0,a_1,…,a_{n-1}. Then for each integer k, the record in storage slot k is moved to storage slot number k+a_{kmod n}.

After this shuffling process, determine if there is still exactly one record assigned to each storage slot. That is, there are no empty slots or storage slots with multiple records.

Input

Each test consists of multiple test cases. The first line contains a single integer t (1≤ t≤ 10^4) — the number of test cases. Next 2t lines contain descriptions of test cases.

The first line of each test case contains a single integer n (1≤ n≤ 2⋅ 10^5) — the length of the array.

The second line of each test case contains n integers a_0,a_1,…,a_{n-1} (-10^9≤ a_i≤ 10^9).

It is guaranteed that the sum of n over all test cases does not exceed 2⋅ 10^5.

Output

For each test case, output a single line containing "YES" if there is exactly one record assigned to each storage slot after the shuffling process, or "NO" otherwise. You can print each letter in any case (upper or lower).

Example

Input


6
1
14
2
1 -1
4
5 5 5 1
3
3 2 1
2

5

Output


YES
YES
YES

YES

Note

In the first test case, every record is shifted by 14 storage slots, so the assignment is still unique.

In the second test case, even records move to the right by 1 storage slot, and odd records move to the left by 1 storage slot. We can show that the assignment is still unique.

In the third test case, every fourth record moves to the right by 1 storage slot, and the other records move to the right by 5 storage slots. We can show that the assignment is still unique.

In the fourth test case, records 0 and 1 are both assigned to storage slot 3.

In the fifth test case, records 1 and 2 are both assigned to storage slot 2.
