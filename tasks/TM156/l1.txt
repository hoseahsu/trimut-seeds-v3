A media service schedules episodes from licensed audio series.

The only difference between easy and hard versions is constraints.

The RelayAudio service every day broadcasts one episode of one of the k Audio series. You know the schedule for the next n days: a sequence of integers a_1, a_2, ..., a_n (1 ≤ a_i ≤ k), where a_i is the series, the episode of which will be shown in i-th day.

The subscription to the series is bought for the entire series (i.e. for all its episodes), for each series the subscription is bought separately.

How many minimum subscriptions do you need to buy in order to have the opportunity to access episodes of purchased series d (1 ≤ d ≤ n) days in a row? In other words, you want to buy the minimum number of Audio series so that there is some segment of d consecutive days in which all episodes belong to the purchased series.

Input

The first line contains an integer t (1 ≤ t ≤ 100) — the number of test cases in the input. Then t test case descriptions follow.

The first line of each test case contains three integers n, k and d (1 ≤ n ≤ 100, 1 ≤ k ≤ 100, 1 ≤ d ≤ n). The second line contains n integers a_1, a_2, ..., a_n (1 ≤ a_i ≤ k), where a_i is the series that is broadcasted on the i-th day.

It is guaranteed that the sum of the values ​​of n for all test cases in the input does not exceed 100.

Output

Print t integers — the answers to the test cases in the input in the order they follow. The answer to a test case is the minimum number of Audio series for which you need to purchase a subscription so that you can access episodes of the purchased Audio series on RelayAudio for d consecutive days. Please note that it is permissible that you will be able to access more than d days in a row.

Example

Input


4
5 2 2
1 2 1 2 1
9 3 3
3 3 3 2 2 2 1 1 1
4 10 4
10 8 6 4
16 9 8
3 1 4 1 5 9 2 6 5 3 5 8 9 7 9 3


Output


2
1
4
5

Note

In the first test case to have an opportunity to access series for two consecutive days, you need to buy a subscription on series 1 and on series 2. So the answer is two.

In the second test case, you can buy a subscription to any series because for each series you can find a segment of three consecutive days, consisting only of episodes of this series.

In the third test case in the unique segment of four days, you have four different series, so you need to buy a subscription to all these four series.

In the fourth test case, you can buy subscriptions to series 3,5,7,8,9, and you will be able to access series for the last eight days.
