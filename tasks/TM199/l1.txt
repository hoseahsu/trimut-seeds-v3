A curator plans a route through scored exhibits along a corridor.

Mira wants to go on a journey across the exhibits of Arden. There are n exhibits situated along the main exhibition corridor of Arden, and these exhibits are numbered from 1 to n. 

Mira plans her journey as follows. First of all, she will choose some exhibit c_1 to start her journey. She will visit it, and after that go to some other exhibit c_2 > c_1, then to some other exhibit c_3 > c_2, and so on, until she chooses to end her journey in some exhibit c_k > c_{k - 1}. So, the sequence of visited exhibits [c_1, c_2, ..., c_k] should be strictly increasing.

There are some additional constraints on the sequence of exhibits Mira visits. Each exhibit i has a appeal value b_i associated with it. If there is only one exhibit in Mira's journey, these appeal values imply no additional constraints. But if there are multiple exhibits in the sequence, then for any pair of adjacent exhibits c_i and c_{i + 1}, the condition c_{i + 1} - c_i = b_{c_{i + 1}} - b_{c_i} must hold.

For example, if n = 8 and b = [3, 4, 4, 6, 6, 7, 8, 9], there are several three possible ways to plan a journey:

  * c = [1, 2, 4]; 
  * c = [3, 5, 6, 8]; 
  * c = [7] (a journey consisting of one exhibit is also valid). 



There are some additional ways to plan a journey that are not listed above.

Mira wants her journey to be as appealing as possible. The appeal value of the whole journey is the sum of appeal values over all visited exhibits. Can you help her to choose the optimal plan, that is, to maximize the appeal value of the journey?

Input

The first line contains one integer n (1 ≤ n ≤ 2 ⋅ 10^5) — the number of exhibits in Arden.

The second line contains n integers b_1, b_2, ..., b_n (1 ≤ b_i ≤ 4 ⋅ 10^5), where b_i is the appeal value of the i-th exhibit.

Output

Print one integer — the maximum appeal of a journey Mira can choose.

Examples

Input


6
10 7 1 9 10 15


Output


26


Input


1
400000


Output


400000


Input


7
8 9 26 11 12 29 14


Output


55

Note

The optimal journey plan in the first example is c = [2, 4, 5].

The optimal journey plan in the second example is c = [1].

The optimal journey plan in the third example is c = [3, 6].
