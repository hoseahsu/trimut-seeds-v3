You are given string S and T consisting of lowercase English letters.

Determine if S equals T after rotation, optionally followed or preceded by one reversal of the whole string.

That is, determine if S equals T after either of the following operations is performed any number of times:

Operation: Let S = S_1 S_2 ... S_{|S|}. Change S to S_{|S|} S_1 S_2 ... S_{|S|-1}.

Reversal operation: Reverse the order of all characters of S.

Here, |X| denotes the length of the string X.

Constraints

* 2 \leq |S| \leq 100
* |S| = |T|
* S and T consist of lowercase English letters.

Input

Input is given from Standard Input in the following format:


S
T


Output

If S equals T after the allowed rotations and reversals, print `Yes`; if it does not, print `No`.

Sample Input 1

```text
kyoto
tokyo
```

Sample Output 1

```text
Yes
```

Sample Input 2

```text
abc
arc
```

Sample Output 2

```text
No
```

Sample Input 3

```text
aaaaaaaaaaaaaaab
aaaaaaaaaaaaaaab
```

Sample Output 3

```text
Yes
```
