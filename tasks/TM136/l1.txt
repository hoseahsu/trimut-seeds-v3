A tournament ledger ranks participants by cumulative score.

The winner of the scoring contest popular in Arden "Berlogging" is determined according to the following rules. If at the end of the contest there is only one participant with the maximum number of points, he is the winner. The situation becomes more difficult if the number of such participants is more than one. During each round a participant gains or loses a particular number of points. In the course of the contest the number of points is registered in the line "name score", where name is a participant's name, and score is the number of points gained in this round, which is an integer number. If score is negative, this means that the participant has lost in the round. So, if two or more participants have the maximum number of points (say, it equals to m) at the end of the contest, than wins the one of them who scored at least m points first. Initially each participant has 0 points. It's guaranteed that at the end of the contest at least one participant has a positive number of points.

Input

The first line contains an integer number n (1 ≤ n ≤ 1000), n is the number of rounds played. Then follow n lines, containing the information about the rounds in "name score" format in chronological order, where name is a string of lower-case Latin letters with the length from 1 to 32, and score is an integer number between -1000 and 1000, inclusive.

Output

Print the name of the winner.

Examples

Input

3
mike 3
andrew 5
mike 2


Output

andrew
