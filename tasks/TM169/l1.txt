The intervals denote coverage zones along a numbered coordinate line.

You are given n coverage zones on a coordinate line; each endpoint of every coverage zone has integer coordinates. Some coverage zones can degenerate to coordinate sites. Coverage zones can intersect with each other, be nested in each other or even coincide.

Your task is the following: for every k ∈ [1..n], calculate the number of coordinate sites with integer coordinates such that the number of coverage zones that cover these coordinate sites equals k. A coverage zone with endpoints l_i and r_i covers coordinate site x if and only if l_i ≤ x ≤ r_i.

Input

The first line of the input contains one integer n (1 ≤ n ≤ 2 ⋅ 10^5) — the number of coverage zones.

The next n lines contain coverage zones. The i-th line contains a pair of integers l_i, r_i (0 ≤ l_i ≤ r_i ≤ 10^{18}) — the endpoints of the i-th coverage zone.

Output

Print n space separated integers cnt_1, cnt_2, ..., cnt_n, where cnt_i is equal to the number of coordinate sites such that the number of coverage zones that cover these coordinate sites equals to i.

Examples

Input

3
0 3
1 3
3 8


Output

6 2 1 


Input

3
1 3
2 4
5 7


Output

5 2 0
