A trainee uses circular shifts to order a numeric register.

One day, Mira is interested in how to sort a numeric register of integers a1, a2, ..., an in non-decreasing order. Being a young trainee, the only operation she can perform is a unit shift. That is, she can move the last element of the numeric register to its beginning:

a1, a2, ..., an → an, a1, a2, ..., an - 1.

Help Mira to calculate: what is the minimum number of operations that she needs to sort the numeric register?

Input

The first line contains an integer n (2 ≤ n ≤ 10^5). The second line contains n integer numbers a1, a2, ..., an (1 ≤ ai ≤ 10^5).

Output

If it's impossible to sort the numeric register output -1. Otherwise output the minimum number of operations Mira needs to sort it.

Examples

Input

2
2 1


Output

1


Input

3
1 3 2


Output

-1


Input

2
1 2


Output

0
