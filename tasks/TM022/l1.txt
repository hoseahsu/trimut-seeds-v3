An outreach coordinator selects speakers with separate audiences.

Nora works in an outreach office. In order to promote the new program, she wants to conclude contracts with some speakers. In total, Nora has connections of n different speakers. Speaker numbered i has a_i audience members.

Since Nora has a limited budget, she can only sign a contract with k different speakers. Of course, Nora wants her announcement to be seen by as many people as possible. Therefore, she must hire speakers with the maximum total number of audience members.

Help her, find the number of ways to select k speakers so that the total number of their audience members is maximum possible. Two ways are considered different if there is at least one speaker in the first way, which is not in the second way. Nora believes that all speakers have different audience members (that is, there is no audience member who would follow two different speakers).

For example, if n=4, k=3, a=[1, 3, 1, 2], then Nora has two ways to select 3 speakers with the maximum total number of audience members: 

  * conclude contracts with speakers with numbers 1, 2 and 4. In this case, the number of audience members will be equal to a_1 + a_2 + a_4 = 6. 
  * conclude contracts with speakers with numbers 2, 3 and 4. In this case, the number of audience members will be equal to a_2 + a_3 + a_4 = 6. 



Since the answer can be quite large, output it modulo 10^9+7.

Input

The first line contains one integer t (1 ≤ t ≤ 1000) — the number of test cases. Then t test cases follow.

The first line of each test case contains two integers n and k (1 ≤ k ≤ n ≤ 1000) — the number of speakers and how many of them you can sign a contract with.

The second line of each test case contains n integers a_1, a_2, … a_n (1 ≤ a_i ≤ n) — the number of audience members of each speaker.

It is guaranteed that the sum of n over all test cases does not exceed 1000.

Output

For each test case, on a separate line output one integer — the number of ways to select k speakers so that the total number of their audience members is maximum possible.

Example

Input


3
4 3
1 3 1 2
4 2
1 1 1 1
2 1
1 2


Output


2
6
1

Note

The test case is explained in the statements.

In the second test case, the following ways are valid: 

  * conclude contracts with speakers with numbers 1 and 2. In this case, the number of audience members will be equal to a_1 + a_2 = 2; 
  * conclude contracts with speakers with numbers 1 and 3. In this case, the number of audience members will be equal to a_1 + a_3 = 2; 
  * conclude contracts with speakers with numbers 1 and 4. In this case, the number of audience members will be equal to a_1 + a_4 = 2; 
  * conclude contracts with speakers with numbers 2 and 3. In this case, the number of audience members will be equal to a_2 + a_3 = 2; 
  * conclude contracts with speakers with numbers 2 and 4. In this case, the number of audience members will be equal to a_2 + a_4 = 2; 
  * conclude contracts with speakers with numbers 3 and 4. In this case, the number of audience members will be equal to a_3 + a_4 = 2. 



In the third test case, the following ways are valid: 

  * concludes a contract with a speaker with the number 2. In this case, the number of audience members will be equal to a_2 = 2.
