The array is a value register whose subarrays carry concentration scores.

An value register of positive integers a1, a2, ..., an is given. Let us consider its arbitrary register interval al, al + 1..., ar, where 1 ≤ l ≤ r ≤ n. For every positive integer s denote by Ks the number of occurrences of s into the register interval. We call the concentration score of the register interval the sum of products Ks·Ks·s for every positive integer s. The sum contains only finite number of nonzero summands as the number of different values in the value register is indeed finite.

You should calculate the concentration score of t given register intervals.

Input

First line contains two integers n and t (1 ≤ n, t ≤ 200000) — the value register length and the number of queries correspondingly.

Second line contains n positive integers ai (1 ≤ ai ≤ 10^6) — the elements of the value register.

Next t lines contain two positive integers l, r (1 ≤ l ≤ r ≤ n) each — the indices of the left and the right ends of the corresponding register interval.

Output

Output t lines, the i-th line of the output should contain single positive integer — the concentration score of the i-th query register interval.

Please, do not use %lld specificator to read or write 64-bit integers in C++. It is preferred to use cout stream (also you may use %I64d).

Examples

Input

3 2
1 2 1
1 2
1 3


Output

3
6


Input

8 3
1 1 2 2 1 3 1 1
2 7
1 6
2 7


Output

20
20
20

Note

Consider the following value register (see the second sample) and its [2, 7] register interval (elements of the register interval are colored): 

![Original illustration 1](https://espresso.codeforces.com/c0d1418a04b13fdf812625d254db5241ce734ac0.png) Then K1 = 3, K2 = 2, K3 = 1, so the concentration score is equal to 3^2·1 + 2^2·2 + 1^2·3 = 20.
