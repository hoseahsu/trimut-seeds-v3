# second moment

## Problem Statement


Given a size $N$ integer sequence $a_0, a_1, \dots, a_{N - 1}$. Process $Q$ queries as follows:

- `0 $l$ $r$ $b$ $c$`: For each $i = l, l+1, \dots, {r - 1}$, $a_i \gets b \times a_i + c$.
- `1 $l$ $r$`: Print $\sum_{i = l}^{r - 1} a_i^2 \bmod 998244353$.


## Constraints

- $1 \leq N, Q \leq 500000$
- $0 \leq a_i, c < 998244353$
- $1 \leq b < 998244353$
- $0 \leq l < r \leq N$

## Input

~~~
$N$ $Q$
$a_0$ $a_1$ ... $a_{N - 1}$
$\textrm{Query}_0$
$\textrm{Query}_1$
:
$\textrm{Query}_{Q - 1}$
~~~


## Sample Input 1

```
5 7
1 2 3 4 5
1 0 5
0 2 4 100 101
1 0 3
0 1 3 102 103
1 2 5
0 2 5 104 105
1 0 5
```

## Sample Output 1

```
55
160806
683416698
742299168
```
