# Junctions

Directed links connect numbered junctions from a designated source.


## Problem Statement


You are given a directed graph, consisting of $N$ junctions and $M$ links. The $i$-th link is directed from junction $u_i$ to junction $v_i$. This graph may not be simple.
You are also given a junction $r$. 

Find the number of directed spanning trees whose root is the junction $r$ (it means that all the junctions have to be reachable from $r$), modulo $998244353$. 



## Constraints

- $1 \leq N \leq 500$
- $0 \leq M \leq 500000$
- $0 \leq r \lt N$
- $0 \leq u_i \lt N$
- $0 \leq v_i \lt N$


## Input

```
$N$ $M$ $r$
$u_0$ $v_0$
$u_1$ $v_1$
$u_2$ $v_2$
$\vdots$
$u_{M-1}$ $v_{M-1}$
```
