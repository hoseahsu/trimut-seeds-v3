# even nonempty subsequences

## Problem Statement


You are given an integer sequence $A$ with length $N$. Count the number of distinct nonempty subsequences of even length of $A$ , modulo $998244353$.



## Constraints

- $1 \leq N \leq 500000$
- $0 \leq A_i \leq 1000000000$

## Input

```
$N$
$A_0$ $A_1$ $\dots$ $A_{N - 1}$
```


## Sample Input 1

```
5
0 0 0 1 1
```

## Sample Output 1

```
5
```

## Sample Input 2

```
9
9 9 8 2 4 4 3 5 3
```

## Sample Output 2

```
125
```
