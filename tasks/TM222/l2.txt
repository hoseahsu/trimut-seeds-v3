# Range Kth Smallest

## Problem Statement


You are given an integer sequence $a_0, a_1, ..., a_{N-1}$ with the length $N$.
Process the following $Q$ queries in order:

- `$l_i$ $r_i$ $k_i$`: Print $k_i+1$ th smallest value in $(a_{l_i}, a_{l_i + 1}, ..., a_{r_i - 1})$.


## Constraints

- $1 \leq N \leq 200000$
- $1 \leq Q \leq 400000$
- $0 \leq a_i \leq 1000000000$
- $0 \leq l_i < r_i \leq N$
- $0 \leq k_i < r_i - l_i$

## Input

~~~
$N$ $Q$
$a_0$ $a_1$ ... $a_{N - 1}$
$l_0$ $r_0$ $k_0$
$l_1$ $r_1$ $k_1$
:
$l_{Q-1}$ $r_{Q-1}$ $k_{Q-1}$
~~~

## Sample Input 1

```
5 3
1 4 0 1 3
0 5 2
1 3 1
3 4 0
```

## Sample Output 1

```
1
4
1
```
