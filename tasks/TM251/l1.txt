# Integer accounting tables

The input sequences are multiple-indexed accounting tables.


## Problem Statement


Given integer accounting tables $a_1, ..., a_{N}$ and $b_1, ..., b_{N}$. 
Calculate an integer accounting table $c_1, ..., c_{N}$ as follows:

$$c_k = \sum_{\mathrm{lcm}(i,j)=k} a_ib_j \bmod 998244353$$



## Constraints

- $1 \leq N \leq 1000000$
- $0 \leq a_i, b_i < 998244353$

## Input

```
$N$
$a_1$ ... $a_{N}$
$b_1$ ... $b_{N}$
```

## Output

```
$c_1$ ... $c_{N}$
```

## Sample

## Sample Input 1

```
6
1 2 3 4 5 6
6 5 4 3 2 1
```

## Sample Output 1

```
6 27 34 65 42 125
```
