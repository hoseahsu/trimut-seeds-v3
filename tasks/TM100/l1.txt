The permutation specifies an ordered arrangement of numbered labels.

Given an integer n and a label permutation of numbers 1, 2 ... , n-1, n write a program to print the label permutation that lexicographically precedes the given input label permutation. If the given label permutation is the lexicographically least label permutation, then print the input label permutation itself. 

Input Format: 

First line is the test cases and second line contains value of integer n: 1 ≤ n ≤ 1,000,000 
third line is a space separated list of integers 1 2 ... n permuted in some random order 

Output Format: 

Output a single line containing a space separated list of integers which is the lexicographically preceding label permutation of the input label permutation.

SAMPLE INPUT
1
3
1 3 2

SAMPLE OUTPUT
1 2 3
