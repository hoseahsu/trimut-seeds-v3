# Range Affine Point Get

## Problem Statement


Given a size $N$ integer sequence $a_0, a_1, \dots, a_{N - 1}$. Process $Q$ queries as follows:

- `0 $l$ $r$ $b$ $c$`: For each $i = l, l+1, \dots, {r - 1}$, $a_i \gets b \times a_i + c$.
- `1 $i$`: Print $a_i \bmod 998244353$.


## Constraints

- $1 \leq N, Q \leq 500000$
- $0 \leq a_i, c < 998244353$
- $1 \leq b < 998244353$
- $0 \leq l < r\leq N$
- $0 \leq i < N$

## Input

~~~
$N$ $Q$
$a_0$ $a_1$ ... $a_{N - 1}$
$\textrm{Query}_0$
$\textrm{Query}_1$
:
$\textrm{Query}_{Q - 1}$
~~~

## Sample Input 1

```
5 12
1 2 3 4 5
0 2 4 100 101
1 0
1 1
1 2
1 3
1 4
0 1 3 102 103
1 0
1 1
1 2
1 3
1 4
```
