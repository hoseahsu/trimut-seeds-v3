Participants share an exact supply of tokens subject to individual bounds.

There are N participants, numbered 1, 2, \ldots, N.

They have decided to share K tokens among themselves. Here, for each i (1 \leq i \leq N), Participant i must receive between 0 and a_i tokens (inclusive). Also, no tokens should be left over.

Find the number of ways for them to share tokens, modulo 10^9 + 7. Here, two ways are said to be different when there exists a participant who receives a different number of tokens.

Constraints

* All values in input are integers.
* 1 \leq N \leq 100
* 0 \leq K \leq 10^5
* 0 \leq a_i \leq K

Input

Input is given from Standard Input in the following format:


N K
a_1 a_2 \ldots a_N


Output

Print the number of ways for the participants to share tokens, modulo 10^9 + 7.

Examples

Input

3 4
1 2 3


Output

5


Input

1 10
9


Output

0


Input

2 0
0 0


Output

1


Input

4 100000
100000 100000 100000 100000


Output

665683269
