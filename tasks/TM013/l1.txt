Two archivists check a rearranged numeric accession label.

One cold archive evening Mira and her older colleague Dorian was sitting at home near the desk and giving each other interesting problems to solve. When it was Mira's turn, she told the number n to Dorian and said:

—Shuffle the digits in this number in order to obtain the smallest possible number without leading zeroes.

—No problem! — said Dorian and immediately gave her an answer.

Mira said a random number, so she doesn't know whether Dorian's answer is correct. Help her to find this out, because impatient colleague is waiting for the verdict.

Input

The first line contains one integer n (0 ≤ n ≤ 10^9) without leading zeroes. The second lines contains one integer m (0 ≤ m ≤ 10^9) — Dorian's answer, possibly with leading zeroes.

Output

Print OK if Dorian's answer is correct and WRONG_ANSWER otherwise.

Examples

Input

3310
1033


Output

OK


Input

4
5


Output

WRONG_ANSWER
