Little Petya likes points a lot. Recently his mom has presented him n points lying on the line OX. Now Petya is wondering in how many ways he can choose three distinct points so that the distance between the two farthest of them is strictly less than d.

Note that the order of the points inside the group of three chosen points doesn't matter.

Input

The first line contains two integers: n and d (1 ≤ n ≤ 10^5; 1 ≤ d ≤ 10^9). The next line contains n integers x1, x2, ..., xn, their absolute value doesn't exceed 10^9 — the x-coordinates of the points that Petya has got.

It is guaranteed that the coordinates of the points in the input strictly increase.

Output

Print a single integer — the number of groups of three points, where the distance between two farthest points is strictly less than d.

Please do not use the %lld specifier to read or write 64-bit integers in С++. It is preferred to use the cin, cout streams or the %I64d specifier.

Sample Input 1

```text
4 3
1 2 3 4
```

Sample Output 1

```text
2
```

Sample Input 2

```text
4 2
-3 -2 -1 0
```

Sample Output 2

```text
0
```

Sample Input 3

```text
5 19
1 10 20 30 50
```

Sample Output 3

```text
0
```
