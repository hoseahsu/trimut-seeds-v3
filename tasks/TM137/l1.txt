A measurement team studies noise readings over consecutive days.

The noise during the last few days has been really intense. Scientists from all over the Arden study how the sound levels and acoustic conditions change, and they claim that this season is abnormally loud. But any scientific claim sounds a lot more reasonable if there are some numbers involved, so they have decided to actually calculate some value which would represent how high the sound levels are.

Mathematicians of Arden State University came up with a special noise intensity value. This value is calculated as follows:

Suppose we want to analyze the segment of n consecutive days. We have measured the sound levels during these n days; the sound level during i-th day equals a_i.

We denote the average sound level of a segment of some consecutive days as the arithmetic mean of the sound level measures during this segment of days. So, if we want to analyze the average sound level from day x to day y, we calculate it as \frac{∑ _{i = x}^{y} a_i}{y - x + 1} (note that division is performed without any rounding). The noise intensity value is the maximum of average sound levels over all segments of not less than k consecutive days. For example, if analyzing the measures [3, 4, 1, 2] and k = 3, we are interested in segments [3, 4, 1], [4, 1, 2] and [3, 4, 1, 2] (we want to find the maximum value of average sound level over these segments).

You have been hired by Arden State University to write a program that would compute the noise intensity value of a given period of days. Are you up to this task?

Input

The first line contains two integers n and k (1 ≤ k ≤ n ≤ 5000) — the number of days in the given period, and the minimum number of days in a segment we consider when calculating noise intensity value, respectively.

The second line contains n integers a_1, a_2, ..., a_n (1 ≤ a_i ≤ 5000) — the sound level measures during given n days.

Output

Print one real number — the noise intensity value, i. e., the maximum of average sound levels over all segments of not less than k consecutive days.

Your answer will be considered correct if the following condition holds: |res - res_0| < 10^{-6}, where res is your answer, and res_0 is the answer given by the jury's solution.

Example

Input

4 3
3 4 1 2


Output

2.666666666666667
