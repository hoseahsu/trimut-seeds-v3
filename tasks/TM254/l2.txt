# Kth Root (Integer)

## Problem Statement


Each test case consist of $T$ cases.

Given $A, K$. Print $\textrm{floor}(a^{1/k})$.


## Constraints

- $1 \leq T \leq 1000000$
- $0 \leq A < 2^{64}$
- $1 \leq K \leq 64$

## Input

```
$T$
$A_0$ $K_0$
$A_1$ $K_1$
:
$A_{T-1}$ $K_{T-1}$
```

## Output


For each line, print the answer.


## Sample

## Sample Input 1

```
10
215 3
216 3
217 3
9999999999 10
10000000000 10
10000000001 10
18446744073709551615 1
18446744073709551615 2
18446744073709551615 63
18446744073709551615 64
```
