# ceiling

## Problem Statement


Each test case consists of $T$ cases.

Given $N, M, A, B$. Print $\sum_{i = 0}^{N - 1} ceil((A \times i + B) / M)$.



## Constraints

- $1 \leq T \leq 100,000$
- $1 \leq N, M \leq 10^9$
- $0 \leq A, B < M$

## Input

```
$T$
$N_0$ $M_0$ $A_0$ $B_0$
$N_1$ $M_1$ $A_1$ $B_1$
:
$N_{T - 1}$ $M_{T - 1}$ $A_{T - 1}$ $B_{T - 1}$
```


## Sample Input 1

```
5
4 10 6 3
6 5 4 3
1 1 0 0
31415 92653 58979 32384
1000000000 1000000000 999999999 999999999
```

## Sample Output 1

```
7
18
0
314126895
500000000499999999
```
