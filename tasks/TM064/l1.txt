The stored array is a lookup register for integer identifiers.

You are given an lookup register A of size N, and Q lookup requests to deal with. For each lookup request, you are given an integer X, and you're supposed to find out if X is present in the lookup register A or not.

Input:
The first line contains two integers, N and Q, denoting the size of lookup register A and number of lookup requests. The second line contains N space separated integers, denoting the lookup register of elements Ai. The next Q lines contain a single integer X per line.

Output:
For each lookup request, print YES if the X is in the lookup register, otherwise print NO.

Constraints:
1 ≤ N, Q ≤ 10^5
1 ≤ Ai ≤ 10^9
1 ≤ X ≤ 10^9
