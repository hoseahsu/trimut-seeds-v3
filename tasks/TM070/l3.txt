# B - Some Sums

## Problem Statement

Find the sum of the integers between $1$ and $N$ (inclusive), whose sum of digits written in base $10$ is at least $A$ and strictly less than $B$.

## Constraints

- $1 \leq N \leq 10^4$

- $1 \leq A \leq B \leq 36$

- All input values are integers.

## Input

Input is given from Standard Input in the following format:

```
N A B

```

## Output

Print the sum of the integers between $1$ and $N$ (inclusive), whose sum of digits written in base $10$ is at least $A$ and strictly less than $B$.

## Sample Input 1

```
20 2 5

```

## Sample Output 1

```
65
```

The upper endpoint is excluded. The qualifying integers are 2, 3, 4, 11, 12, 13, and 20; their sum is 65.

## Sample Input 2

```
10 1 2

```

## Sample Output 2

```
11
```

## Sample Input 3

```
100 4 16

```

## Sample Output 3

```
4290
```
