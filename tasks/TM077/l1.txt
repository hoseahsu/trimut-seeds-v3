A performer edits a written chant for a gatekeeper.

After his wife's tragic death, Mira, Nolan descended to the realm of death to see her. Reaching its gates was uneasy, but passing through them proved to be even more challenging. Mostly because of Voss, the three-headed gatekeeper of Arden. 

Nolan, a famous performer, and musician plans to calm Voss with his chants and safely walk past him. He created a very peculiar chant for Voss. It consists only of lowercase English letters. 

We call a chant's substring a palindrome if and only if it reads the same backwards and forwards. A string a is a substring of a string b if a can be obtained from b by deleting several (possibly zero or all) characters from the beginning and several (possibly zero or all) characters from the end.

Unfortunately, Voss dislikes palindromes of length greater than 1. For example in the chant abaa the gatekeeper of Arden wouldn't like substrings aba and aa.

Nolan can only calm Voss if the gatekeeper likes his chants. That's why he wants to change his chant so that it does not contain any palindrome substrings of length greater than 1.

Nolan can modify the chant by replacing a letter at any position with any lowercase English letter. He can use this operation arbitrarily many times (possibly zero). Since there can be many palindromes in his chant, he may have to make some corrections. But how many, exactly? Given the chant, determine the minimal number of letters that have to be changed so that the chant does not contain any palindromes of length greater than 1.

Input

The first line of the input contains a single integer t (1 ≤ t ≤ 10^5) denoting the number of test cases, then t test cases follow.

The first and only line of each test case contains a non-empty string of lowercase English letters, Nolan' chant.

The sum of the length of Nolan' poems in all test cases will not exceed 10^5.

Output

You should output t lines, i-th line should contain a single integer, answer to the i-th test case.

Example

Input


7
babba
abaac
codeforces
zeroorez
abcdcba
bbbbbbb
a


Output


1
1
0
1
1
4
0

Note

In the first test case, we can replace the third character with c and obtain a palindrome-less chant bacba.

In the second test case, we can replace the third character with d and obtain a palindrome-less chant abdac.

In the third test case, the initial chant already doesn't contain any palindromes, so Nolan doesn't need to change anything there.
