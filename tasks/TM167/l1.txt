Nested carrying units hide smaller units subject to the stated size rule.

There are n carrying units with compartments. Each carrying unit has a size (integer number). A carrying unit can go into another carrying unit's compartment if and only if the size of carrying unit who hold the carrying unit is at least twice as large as the size of carrying unit who is held.

Each carrying unit can hold at most one carrying unit, and the carrying unit who is held by another carrying unit cannot hold any carrying units.

The carrying unit who is held by another carrying unit cannot be visible from outside. Please, find a plan of holding carrying units with the minimal number of carrying units who is visible.

Input

The first line contains a single integer — n (1 ≤ n ≤ 5·10^5). Each of the next n lines contains an integer si — the size of the i-th carrying unit (1 ≤ si ≤ 10^5).

Output

Output a single integer — the optimal number of visible carrying units.
