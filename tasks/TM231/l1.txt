# Integer balance ledger

The integer sequence is a ledger of adjustable balances.


## Problem Statement


Given a size $N$ integer balance ledger $a_0, a_1, \dots, a_{N - 1}$. Process the following $Q$ ledger requests in order:

- `0 $l$ $r$ $x$`: For each $i = l, l+1, \dots, {r - 1}$, $a_i \gets a_i + x$.
- `1 $l$ $r$`: Print $\min_{l \le i \le r-1} a_i$.


## Constraints


- $1 \leq N, Q \leq 500000$
- $|a_i|, |x| \leq 1000000000$
- $0 \leq l < r \leq N$
- The values in input are all integers．



## Input

~~~
$N$ $Q$
$a_0$ $a_1$ ... $a_{N - 1}$
$\textrm{Query}_0$
$\textrm{Query}_1$
:
$\textrm{Query}_{Q - 1}$
~~~

## Sample Input 1

```
5 7
1 2 3 4 5
1 0 5
0 0 3 3
1 1 4
0 1 4 -5
1 0 3
0 4 5 -100
1 0 5
```

## Sample Output 1

```
1
4
0
-95
```
