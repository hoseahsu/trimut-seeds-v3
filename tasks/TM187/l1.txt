Numbered performers prepare a circular procession.

There are n performers standing in a circle in some order. The index of the i-th performer is p_i. It is guaranteed that all indices of performers are distinct integers from 1 to n (i. e. they form a permutation).

Performers want to start a circular procession. A clockwise circular procession can be started if the performer 2 comes right after the performer 1 in clockwise order (there are no performers between them), the performer 3 comes right after the performer 2 in clockwise order, and so on, and the performer n comes right after the performer n - 1 in clockwise order. A counterclockwise circular procession is almost the same thing — the only difference is that the performer i should be right after the performer i - 1 in counterclockwise order (this condition should be met for every i from 2 to n). 

For example, if the indices of performers listed in clockwise order are [2, 3, 4, 5, 1], then they can start a clockwise circular procession. If the performers have indices [3, 2, 1, 4] in clockwise order, then they can start a counterclockwise circular procession.

Your task is to determine whether it is possible to start a circular procession. Note that the performers cannot change their positions before starting the procession; they cannot swap or leave the circle, and no other performer can enter the circle. 

You have to answer q independent queries.

Input

The first line of the input contains one integer q (1 ≤ q ≤ 200) — the number of queries. Then q queries follow.

The first line of the query contains one integer n (1 ≤ n ≤ 200) — the number of performers.

The second line of the query contains a permutation of indices p_1, p_2, ..., p_n (1 ≤ p_i ≤ n), where p_i is the index of the i-th performer (in clockwise order). It is guaranteed that all p_i are distinct integers from 1 to n (i. e. they form a permutation).

Output

For each query, print the answer on it. If a circular procession can be started with the given order of performers, print "YES". Otherwise print "NO".

Example

Input


5
4
1 2 3 4
3
1 3 2
5
1 2 3 5 4
1
1
5
3 2 1 5 4


Output


YES
YES
NO
YES
YES
