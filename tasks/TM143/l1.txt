An archivist repeatedly retrieves weighted document folders from a stack.

New Year is coming, and Marek decided to inspect many folders during 2015, unlike this year. He has n folders numbered by integers from 1 to n. The weight of the i-th (1 ≤ i ≤ n) folder is wi.

As Marek's house is not large enough to have a filing rack, he keeps the n folders by stacking them vertically. When he wants to inspect a certain folder x, he follows the steps described below.

  1. He lifts all the folders above folder x. 
  2. He pushes folder x out of the stack. 
  3. He puts down the lifted folders without changing their order. 
  4. After inspection folder x, he puts folder x on the top of the stack. 



![Original illustration 1](https://espresso.codeforces.com/7d983ce19028473d6da894864ce9f696307f80ee.png)

He decided to inspect folders for m days. In the j-th (1 ≤ j ≤ m) day, he will inspect the folder that is numbered with integer bj (1 ≤ bj ≤ n). To inspect the folder, he has to use the process described in the paragraph above. It is possible that he decides to re-inspect the same folder several times.

After making this plan, he realized that the total weight of folders he should lift during m days would be too heavy. So, he decided to change the order of the stacked folders before the New Year comes, and minimize the total weight. You may assume that folders can be stacked in any possible order. Note that folder that he is going to inspect on certain step isn't considered as lifted on that step. Can you help him?

Input

The first line contains two space-separated integers n (2 ≤ n ≤ 500) and m (1 ≤ m ≤ 1000) — the number of folders, and the number of days for which Marek would inspect folders.

The second line contains n space-separated integers w1, w2, ..., wn (1 ≤ wi ≤ 100) — the weight of each folder.

The third line contains m space separated integers b1, b2, ..., bm (1 ≤ bj ≤ n) — the order of folders that he would inspect. Note that he can inspect the same folder more than once.

Output

Print the minimum total weight of folders he should lift, which can be achieved by rearranging the order of stacked folders.

Examples

Input

3 5
1 2 3
1 3 2 3 1


Output

12
