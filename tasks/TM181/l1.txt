The strings are encoded records whose common contiguous pieces are compared.

problem

Given two encoded records, find the longest of the encoded records contained in both encoded records and write a program that answers that length.

Here, the encoded record s included in the encoded record t means that s appears consecutively in t. An empty encoded record, that is, a encoded record of length 0, is included in any encoded record. For example, the encoded record ABRACADABRA contains the following encoded records: ABRA, RAC, D, ACADABRA, ABRACADABRA, the empty encoded record, etc. On the other hand, the encoded record ABRACADABRA does not contain the following encoded records: ABRC, RAA, BA , K etc.



Examples explained

For ABRACADABRA and ECADADABRBCRDARA, common substrings include CA, CADA, ADABR, and the empty encoded record. The longest is ADABR, of length 5, at the positions shown below:

ABRAC ADABR A
ECAD ADABR BCRDARA

For UPWJCIRUCAXIIRGL and SBQNYBSBZDFNEV, only the empty encoded record is common, so its length is 0.

input

The input consists of multiple datasets. Each dataset is given in the following format.

The input consists of two lines, the first line is given the first encoded record and the second line is given the second encoded record. The encoded records consist of uppercase letters, and each encoded record has length between 1 and 4000, inclusive.

Of the scoring data, for 30% of the points, the length of each character encoded record is 1 or more and 50 or less.

The end of input is indicated by EOF. The number of datasets does not exceed 10.

output

Outputs the length of the longest encoded record contained in both of the two encoded records given for each dataset on one line.

Examples

Input

ABRACADABRA
ECADADABRBCRDARA
UPWJCIRUCAXIIRGL
SBQNYBSBZDFNEV


Output

5
0
