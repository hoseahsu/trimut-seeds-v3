problem

Given two strings, find the length of their longest common subsequence.

Here s is a subsequence of t if s can be obtained by removing zero or more characters from t without changing the order of the remaining characters. The empty string is a subsequence of every string.




input

The input consists of multiple datasets. Each dataset is given in the following format.

The input consists of two lines, the first line is given the first string and the second line is given the second string. The strings consist of uppercase letters, and each string has length between 1 and 4000, inclusive.

Of the scoring data, for 30% of the points, the length of each character string is 1 or more and 50 or less.

The end of input is indicated by EOF. The number of datasets does not exceed 10.

output

Outputs the length of the longest common subsequence of the two strings given for each dataset on one line.

Sample Input 1

```text
ABRACADABRA
ECADADABRBCRDARA
UPWJCIRUCAXIIRGL
SBQNYBSBZDFNEV
```

Sample Output 1

```text
8
0
```
