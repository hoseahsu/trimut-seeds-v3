# Terminals

A changing network connects terminals carrying recorded quantities.


## Problem Statement


You are given an empty graph with $N$ terminals. The $i$-th terminal has a value $a_i$ written on it.

Process $Q$ queries:

- `0 $u$ $v$` : Add an connection between terminal $u$ and terminal $v$. (It is guaranteed that, immediately before this query, there is no connection between terminal $u$ and terminal $v$)
- `1 $u$ $v$` : Remove the connection between terminal $u$ and terminal $v$. (It is guaranteed that, immediately before this query, there is an connection between terminal $u$ and terminal $v$)
- `2 $v$ $x$` : $a_v \gets a_v + x$
- `3 $v$ `   : Output the sum of values on all terminals that are connected to terminal $v$ by a path.





## Constraints

- $1 \leq N, Q \leq 300000$
- $0 \leq a_i, x \leq 1000000000$
- $0 \leq u_i, v_i < N$
- $u_i \neq v_i$

## Input

~~~
$N$ $Q$
$a_0$ $a_1$ ... $a_{N - 1}$
$\textrm{Query}_0$
$\textrm{Query}_1$
:
$\textrm{Query}_{Q - 1}$
~~~

## Sample Input 1

```

0 1 2

0 3 4
0 0 4
3 3
1 1 2
3 1
1 3 4

```

