A craftsman builds two types of ornaments from rods and crystals.

Marek plays a well-known computer game (we won't mention its name). In this game, he can craft tools of two types — pendants and brooches. To craft a pendant, Marek spends two rods and one crystal; to craft a brooch, Marek spends two crystals and one rod.

Each tool can be sold for exactly one credit. How many credits can Marek earn, if he has a rods and b crystals?

Input

The first line contains one integer t (1 ≤ t ≤ 1000) — the number of test cases.

The only line of each test case contains two integers a and b (0 ≤ a, b ≤ 10^9) — the number of rods and the number of crystals, respectively.

Output

For each test case print one integer — the maximum number of credits Marek can earn.

Example

Input


4
4 4
1000000000 0
7 15
8 7


Output


2
0
7
5

Note

In the first test case Marek can earn two credits as follows: craft one brooch and one pendant.

In the second test case Marek does not have any crystals, so he cannot craft anything.
