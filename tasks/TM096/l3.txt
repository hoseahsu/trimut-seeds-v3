Strings can be efficiently stored as a data structure, to have efficient searching methods.
A new startup is going to use this method, but they don't have much space. So they want to check beforehand how much memory will be required for their data. 
The engineers now reverse each word before inserting it into a trie. Consequently the structure shares suffixes of the original words, rather than prefixes. Count every trie node, including the empty root.

For example, for the five words et, eq, bd, be, bdp, insert te, qe, db, eb, pdb into the trie. The root has children t, q, d, e and p. Their respective branches contain 2, 2, 2, 2 and 3 nodes excluding the root, so the total required number of nodes is 12.

Input: 
First line contains N, the number of strings they have.  
Each of the next N lines contain one string. Each string consists only of lowercase letters.    

Output: 
Print the required number of nodes.    

**Constraints: 
1 ≤ N ≤ 10^5     
Length of each string  ≤ 30    

Note: No two strings are same, though one string could be prefix of another.

Sample Input 1

```text
5
et
eq
bd
be
bdp
```

Sample Output 1

```text
12
```
