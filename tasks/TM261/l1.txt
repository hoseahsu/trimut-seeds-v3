# Rectangular coverage zones

The rectangles are planar coverage zones.


## Problem Statement

Given $N$ rectangular coverage zones : the $i$-th rectangular coverage zone is represented by $\lbrace (x,y):l_i \leq x \leq r_i,d_i \leq y \leq u_i \rbrace$. Output the area of the union set of these rectangular coverage zones.



## Constraints


 - $1 \le N \le 500000$
 - $0 \le l_i < r_i \le 1000000000$
 - $0 \le d_i < u_i \le 1000000000$



## Input
~~~
$N$
$l_0$ $d_0$ $r_0$ $u_0$
$l_1$ $d_1$ $r_1$ $u_1$
$\vdots$
$l_{N-1}$ $d_{N-1}$ $r_{N-1}$ $u_{N-1}$
~~~

## Sample Input 1

```
3
1 1 2 5
2 1 5 2
1 2 2 5
```

## Sample Output 1

```
7
```
