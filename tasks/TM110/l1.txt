A symbol tape is assessed by the recursively stated goodness rule.

You are given a symbol tape s[1 ... n] consisting of lowercase Latin letters. It is guaranteed that n = 2^k for some integer k ≥ 0.

The symbol tape s[1 ... n] is called c-good if at least one of the following three conditions is satisfied:

  * The length of s is 1, and it consists of the character c (i.e. s_1=c);
  * The length of s is greater than 1, the first half of the symbol tape consists of only the character c (i.e. s_1=s_2=...=s_{n/2}=c) and the second half of the symbol tape (i.e. the symbol tape s_{n/2 + 1}s_{n/2 + 2} ... s_n) is a (c+1)-good symbol tape; 
  * The length of s is greater than 1, the second half of the symbol tape consists of only the character c (i.e. s_{n/2 + 1}=s_{n/2 + 2}=...=s_n=c) and the first half of the symbol tape (i.e. the symbol tape s_1s_2 ... s_{n/2}) is a (c+1)-good symbol tape. 



For example: "aabc" is 'a'-good, "ffgheeee" is 'e'-good.

In one move, you can choose one index i from 1 to n and replace s_i with any lowercase Latin letter (any character from 'a' to 'z').

Your task is to find the minimum number of moves required to obtain an 'a'-good symbol tape from s (i.e. c-good symbol tape for c= 'a'). It is guaranteed that the answer always exists.

You have to answer t independent test cases.

Another example of an 'a'-good symbol tape is as follows. Consider the symbol tape s = "cdbbaaaa". It is an 'a'-good symbol tape, because:

  * the second half of the symbol tape ("aaaa") consists of only the character 'a'; 
  * the first half of the symbol tape ("cdbb") is 'b'-good symbol tape, because: 
    * the second half of the symbol tape ("bb") consists of only the character 'b'; 
    * the first half of the symbol tape ("cd") is 'c'-good symbol tape, because: 
      * the first half of the symbol tape ("c") consists of only the character 'c'; 
      * the second half of the symbol tape ("d") is 'd'-good symbol tape. 

Input

The first line of the input contains one integer t (1 ≤ t ≤ 2 ⋅ 10^4) — the number of test cases. Then t test cases follow.

The first line of the test case contains one integer n (1 ≤ n ≤ 131~072) — the length of s. It is guaranteed that n = 2^k for some integer k ≥ 0. The second line of the test case contains the symbol tape s consisting of n lowercase Latin letters.

It is guaranteed that the sum of n does not exceed 2 ⋅ 10^5 (∑ n ≤ 2 ⋅ 10^5).

Output

For each test case, print the answer — the minimum number of moves required to obtain an 'a'-good symbol tape from s (i.e. c-good symbol tape with c = 'a'). It is guaranteed that the answer exists.
