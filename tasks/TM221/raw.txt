# Static RMQ

## Problem Statement


You are given an integer sequence $a_0, a_1, ..., a_{N-1}$ with the length $N$.
Process the following $Q$ queries in order:

- `$l_i$ $r_i$`: Print $\min(a_{l_i}, a_{l_i + 1}, ..., a_{r_i - 1})$.


## Constraints

- $1 \leq N, Q \leq 500000$
- $0 \leq a_i \leq 10^9$
- $0 \leq l_i < r_i \leq N$

## Input

~~~
$N$ $Q$
$a_0$ $a_1$ ... $a_{N - 1}$
$l_1$ $r_1$
$l_2$ $r_2$
:
$l_Q$ $r_Q$
~~~

## Sample Input 1

```
4 10
2 10 1 100
0 1
0 2
0 3
0 4
1 2
1 3
1 4
2 3
2 4
3 4
```

## Sample Output 1

```
2
2
1
1
10
1
1
1
1
100
```
