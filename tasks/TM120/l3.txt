There are N islands and M bridges.

The i-th bridge connects the A_i-th and B_i-th islands bidirectionally.

Initially no bridge has been built, so distinct islands are disconnected. The complete set of M proposed bridges connects all N islands.

Build the bridges in the order from the first bridge to the M-th bridge.

Let the inconvenience be the number of pairs of islands (a, b) (a < b) such that we are unable to travel between the a-th and b-th islands using some of the bridges built so far.

For each i (1 \leq i \leq M), find the inconvenience just after the i-th bridge is built.

Constraints

* All values in input are integers.
* 2 \leq N \leq 10^5
* 1 \leq M \leq 10^5
* 1 \leq A_i < B_i \leq N
* All pairs (A_i, B_i) are distinct.
* The graph formed by all M listed bridges is connected; after all bridges are built, the inconvenience is 0.

Input

Input is given from Standard Input in the following format:


N M
A_1 B_1
A_2 B_2
\vdots
A_M B_M


Output

In the order i = 1, 2, ..., M, print the inconvenience just after the i-th bridge is built. Note that the answer may not fit into a 32-bit integer type.

Sample Input 1

```text
4 5
1 2
3 4
1 3
2 3
1 4
```

Sample Output 1

```text
5
4
0
0
0
```

Sample Input 2

```text
6 5
2 3
1 2
5 6
3 4
4 5
```

Sample Output 2

```text
14
12
11
8
0
```

Sample Input 3

```text
2 1
1 2
```

Sample Output 3

```text
0
```
