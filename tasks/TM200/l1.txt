Propagation sources set levels along a strip according to distance.

On a strip of display surface of length n there are k propagation sources: the i-th propagation source is placed in cell a_i (1 ≤ a_i ≤ n). Two or more propagation sources cannot be placed in the same cell (i.e. all a_i are distinct).

Each propagation source is characterized by one parameter: signal level. The i-th propagation source is set to the signal level t_i.

![Original illustration 1](https://espresso.codeforces.com/d603b553d049b7bf9a634f173e94f1e4d86e0053.png) Example of strip of length n=6, where k=2, a=[2,5] and t=[14,16].

For each cell i (1 ≤ i ≤ n) find it's signal level, that can be calculated by the formula $$$min_{1 ≤ j ≤ k}(t_j + |a_j - i|),$$$

where |a_j - i| denotes absolute value of the difference a_j - i.

In other words, the signal level in cell i is equal to the minimum among the signal levels of propagation sources, increased by the distance from it to the cell i.

Let's look at an example. Consider that n=6, k=2, the first propagation source is placed in cell a_1=2 and is set to the signal level t_1=14 and the second propagation source is placed in cell a_2=5 and is set to the signal level t_2=16. In that case signal levels in cells are:

  1. signal level in cell 1 is: min(14 + |2 - 1|, 16 + |5 - 1|)=min(14 + 1, 16 + 4)=min(15, 20)=15; 
  2. signal level in cell 2 is: min(14 + |2 - 2|, 16 + |5 - 2|)=min(14 + 0, 16 + 3)=min(14, 19)=14; 
  3. signal level in cell 3 is: min(14 + |2 - 3|, 16 + |5 - 3|)=min(14 + 1, 16 + 2)=min(15, 18)=15; 
  4. signal level in cell 4 is: min(14 + |2 - 4|, 16 + |5 - 4|)=min(14 + 2, 16 + 1)=min(16, 17)=16; 
  5. signal level in cell 5 is: min(14 + |2 - 5|, 16 + |5 - 5|)=min(14 + 3, 16 + 0)=min(17, 16)=16; 
  6. signal level in cell 6 is: min(14 + |2 - 6|, 16 + |5 - 6|)=min(14 + 4, 16 + 1)=min(18, 17)=17. 



For each cell from 1 to n find the signal level in it.

Input

The first line contains one integer q (1 ≤ q ≤ 10^4) — the number of test cases in the input. Then test cases follow. Before each test case, there is an empty line.

Each test case contains three lines. The first line contains two integers n (1 ≤ n ≤ 3 ⋅ 10^5) and k (1 ≤ k ≤ n) — the length of the strip of display surface and the number of propagation sources respectively.

The second line contains k integers a_1, a_2, …, a_k (1 ≤ a_i ≤ n) — positions of propagation sources on the strip of display surface.

The third line contains k integers t_1, t_2, …, t_k (1 ≤ t_i ≤ 10^9) — signal levels of propagation sources.

It is guaranteed that the sum of n over all test cases does not exceed 3 ⋅ 10^5.

Output

For each test case output n integers separated by space: signal levels of air in cells.
