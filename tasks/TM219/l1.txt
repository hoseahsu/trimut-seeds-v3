An analyst partitions a coded tape into balanced portions.

Marek got bored playing with the arrays all the time. Therefore he has decided to buy a coded tape S consists of N lower case alphabets. Once he purchased the coded tape, He starts formulating his own terminologies over his coded tape S. Marek calls a coded tape str A Balanced Coded tape if and only if the characters of the coded tape str can be paritioned into two multisets M1 and M2 such that M1= M2 .

For eg:

Coded tapes like "abccba" , "abaccb" , "aabbcc" are all balanced coded tapes as their characters can be partitioned in the two multisets M1 and M2 such that M1 = M2.

M1 = {a,b,c}

M2 = {c,b,a}

whereas coded tapes like ababab , abcabb are not balanced at all.

Marek wants to break the coded tape he has purchased into some number of tape segments so that each substring is a balanced coded tape . However he does not want break the coded tape into too many tape segments, otherwise the average size of his coded tapes will become small. What is the minimum number of tape segments in which the given coded tape can be broken so that each substring is a balanced coded tape. 

 Input 
First line of input contains a single integer T denoting the number of test cases. First and the only line of each test case contains a coded tape consists of lower case alphabets only denoting coded tape  S .

 Output 
For each test case, print the minimum number of tape segments in which the given coded tape can be broken so that each substring is a balanced coded tape. If it is not possible the given coded tape according to the requirement print  -1 .   

 Constraints 
1 ≤ T ≤ 10^5

1 ≤ |S| ≤ 10^5

S consists of lower case alphabets only.

NOTE : sum of |S| over all the test case will not exceed 10^6.

SAMPLE INPUT
3
elle
jason
immi SAMPLE OUTPUT
1
-1

Test 1 :
Given string "elle" is itself a balanced string . Therefore, the minimum number of strings in which we can divide the given string such that each part is a balanced string is 1 . 

Test 2 :
Given string "jason" can't be divide into some strings such that each part is a balanced string .

Test 3 :
Given string "immi" is itself a balanced string . Therefore, the minimum number of strings in which we can divide the given string such that each part is a balanced string is 1 .
