You are given string s. Your task is to determine if the given string s contains two non-overlapping substrings "AB" and "BA" (the substring "AB" must come before the substring "BA").

Input

The only line of input contains a string s of length between 1 and 10^5 consisting of uppercase Latin letters.

Output

Print "YES" (without the quotes), if string s contains non-overlapping "AB" followed by "BA", and "NO" otherwise.

Sample Input 1

```text
ABA
```

Sample Output 1

```text
NO
```

Sample Input 2

```text
AXBYBXA
```

Sample Output 2

```text
NO
```

Sample Input 3

```text
BACFAB
```

Sample Output 3

```text
NO
```
