Find the number of integers between 1 and N (inclusive) that contains at most K non-zero digits when written in base ten.

Constraints

* 1 \leq N < 10^{100}
* 1 \leq K \leq 3

Input

Input is given from Standard Input in the following format:


N
K


Output

Print the count.

Sample Input 1

```text
100
1
```

Sample Output 1

```text
19
```

Sample Input 2

```text
25
2
```

Sample Output 2

```text
25
```

Sample Input 3

```text
314159
2
```

Sample Output 3

```text
985
```

Sample Input 4

```text
9999999999999999999999999999999999999999999999999999999999999999999999999999999999999999999999999999
3
```

Sample Output 4

```text
118281150
```
