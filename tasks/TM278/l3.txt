# rooted spanning forests

## Problem Statement


You are given an undirected graph, consisting of $N$ vertices and $M$ edges. The $i$-th edge connects vertex $u_i$ and $v_i$. This graph may not be simple.

Find the number of pairs consisting of a spanning forest of the graph and one selected root vertex in each component. Parallel edge instances are distinct choices; self-loops cannot belong to a forest. Count these pairs modulo $998244353$. 



## Constraints

- $1 \leq N \leq 500$
- $0 \leq M \leq 500000$
- $0 \leq u_i \lt N$
- $0 \leq v_i \lt N$


## Input

```
$N$ $M$
$u_0$ $v_0$
$u_1$ $v_1$
$u_2$ $v_2$
$\vdots$
$u_{M-1}$ $v_{M-1}$
```


## Sample Input 1

```
3 5
0 1
0 1
1 2
2 1
2 0
```

## Sample Output 1

```
35
```

## Sample Input 2

```
1 2
0 0
0 0
```

## Sample Output 2

```
1
```

```

```
