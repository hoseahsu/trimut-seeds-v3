# Junctions

The graph connects numbered junctions through distinct links.


## Problem Statement


You are given an undirected graph, consisting of $N$ junctions and $M$ links. The $i$-th link connects junction $u_i$ and $v_i$. This graph may not be simple.

Find the number of spanning trees of the graph modulo $998244353$. 



## Constraints

- $1 \leq N \leq 500$
- $0 \leq M \leq 500000$
- $0 \leq u_i \lt N$
- $0 \leq v_i \lt N$


## Input

```
$N$ $M$
$u_0$ $v_0$
$u_1$ $v_1$
$u_2$ $v_2$
$\vdots$
$u_{M-1}$ $v_{M-1}$
```
