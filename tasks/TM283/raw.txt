# Static Range Sum with Upper Bound

## Problem Statement


Given a size $N$ sequence $a_0, a_1, \dots, a _ {N - 1}$. Process the following $Q$ queries in order:

- `$l$ $r$ $x$`: Print the number and the sum of the elements among $a_l,a_{l+1},...,a_{r-1}$ that are not greater than $x$



## Constraints



- $1 \leq N, Q \leq 500000$
- $0 \leq a_i \leq 1000000000$
- $0 \leq l \leq r \leq N$
- $0 \leq x \leq 1000000000$



## Input

~~~
$N$ $Q$
$a_0$ $a_1$ ... $a_{N - 1}$
$l_0$ $r_0$ $x_0$
$l_1$ $r_1$ $x_1$
:
$l_{Q-1}$ $r_{Q-1}$ $x_{Q-1}$
~~~

## Sample Input 1

```
9 4
3 2 5 2 1 4 3 2 1
1 4 2
2 9 3
0 8 4
7 7 5
```

## Sample Output 1

```
2 4
5 9
7 17
0 0
```
